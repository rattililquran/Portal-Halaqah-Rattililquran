🌱 Pengembangan Pengajar

Membina & mengukur mutu pengajar: jenjang, tashih, program pembinaan, evaluasi, apresiasi, dan halaqah pengajar.

Sidebar admin → 🌱 Pengembangan Pengajar. Modul punya beberapa tab. Sebagian aksi (ubah jenjang, kelola Indikator) khusus Superadmin. Bendahara tidak melihat modul ini.

Filosofi program: dibina bersama, bukan sekadar dinilai. Komponen top-down (tashih/evaluasi) menjaga standar; halaqah pengajar (peer) adalah jantung kebersamaan.

👤 Profil & Jenjang

Daftar seluruh pengajar beserta jenjang (Pemula → Madya → Utama/Musyrif) dan status sertifikasi.

  • Jenjang (Superadmin): pilih dari dropdown → otomatis tercatat ke riwayat jenjang (audit) & ter-log.
  • Sertifikasi: klik badge untuk beralih orientasi ⇄ tersertifikasi. Guru orientasi = dalam pendampingan.
  • Edit: isi sanad/talaqqi & jumlah hafalan (juz).
Perubahan jenjang hanya lewat tombol ini agar audit terjaga — bukan lewat edit profil.

📅 Program Pembinaan (to-do)

Daftar kegiatan pembinaan yang berangkat dari dua sumber:

🩹 Dari Keresahan — mulai dari masalah nyata: Masalah → Eksekusi → Target. Contoh: "banyak guru telat" → "check-in 10 menit + briefing" → "tepat waktu ≥95%". Bisa ditandai Selesai saat teratasi.
🌱 Dari Kebaikan — ciri guru terbaik yang dikejar lewat belajar (ilmu) + praktik (amal), ditautkan ke indikator evaluasi terukur.
  1. + To-do Pembinaan → pilih sumber (Keresahan/Kebaikan).
  2. Gunakan chip pustaka (siap-pakai) untuk mengisi cepat, lalu sunting bebas.
  3. Isi ranah/ikhtiar/indikator/frekuensi/jadwal (semua opsional).
  4. 🔔 Ingatkan → kirim notifikasi ke seluruh guru aktif.
Saat kegiatan benar-benar dilaksanakan, catat sebagai Pelatihan (tab berikutnya) agar terhitung "N× dilaksanakan".

🎓 Pelatihan

Event pelatihan nyata + kehadiran.

  1. + Pelatihan Baru (atau klik chip template untuk judul siap-pakai) → isi judul, tanggal, kategori.
  2. Klik ✓ Kehadiran → centang H (hadir) / I (izin) / A (alpa) tiap guru.

📊 Mutaba'ah & Rapor

Dashboard agregat + rapor per pengajar. Pilih pengajar untuk melihat:

  • Nilai evaluasi terakhir, % kehadiran (dari absensi), capaian murid (dari raport), tashih lulus, Micro Teaching, mutaba'ah terbuka.
  • Riwayat Tashih & Evaluasi lengkap.
  • 🏅 Apresiasi: beri penghargaan (teladan/kehadiran/dedikasi).
  • 👁️ Observasi KBM (Superadmin): temuan ketua kelas → tombol → Mutaba'ah untuk menindaklanjuti.
% Kehadiran & Capaian Murid ditarik otomatis dari data absensi & raport — tak perlu input ulang.

🤝 Halaqah Pengajar (peer)

Kelola lingkaran belajar antar-guru (saling setor makhraj/sifat/dalil).

  1. + Kelompok Pengajar → beri nama, fokus, jadwal.
  2. Atur Anggota → centang guru anggota.
  3. 🔔 Ingatkan → dorong anggota melanjutkan setoran.
Rekap peer bersifat apresiatif (kelompok paling aktif), bukan papan peringkat yang mempermalukan.

⚙️ Indikator (Superadmin)

Master indikator evaluasi + bobot. Total bobot ideal = 100. Default: Kefasihan 30, Keterampilan mengajar 25, Capaian murid 20, Kedisiplinan 15, Adab 10.

Panel Guru & Musyrif

Guru mengakses 🌱 Pengembangan Diri di portal guru untuk halaqah peer & profil dirinya. Guru ber-flag Musyrif mendapat tab Binaan untuk input tashih/evaluasi/mutaba'ah. Tetapkan Musyrif lewat data pengguna (is_musyrif).
